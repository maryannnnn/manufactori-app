# Agents

This project uses the Payload CMS skill at `.agents/skills/payload/`.
Start with `.agents/skills/payload/SKILL.md` for a quick reference, then see `.agents/skills/payload/reference/` for detailed docs.

## Prompts

- `.agents/prompts/case-study-generation.md` — turning supplied client material into a
  complete Case Study, including the required FAQ and expert discussion. Read it before
  generating or extending any case study.
- `.agents/prompts/promtehmontg-case-study.md` — PromTehMontg addendum: facade materials,
  product categories, mounting subsystems, gallery subjects, and SEO intent groups.
  Read it together with the general Case Study prompt when creating or updating that case.
